# Python-data-structures

Proyecto académico desarrollado en Python durante la Tecnicatura Universitaria en Programación (UTN).

## Descripción

Aplicación de consola desarrollada en Python que implementa distintas operaciones sobre listas y matrices, utilizando funciones propias, validaciones de entrada y estructuras de control.

El objetivo del proyecto fue aplicar conceptos fundamentales de programación mediante la resolución de diferentes ejercicios prácticos.

## Funcionalidades

- Generación de listas aleatorias.
- Búsqueda de elementos.
- Ordenamiento de datos.
- Manipulación de matrices.
- Validación de datos ingresados por el usuario.
- Menú interactivo por consola.
- Modularización mediante funciones.
